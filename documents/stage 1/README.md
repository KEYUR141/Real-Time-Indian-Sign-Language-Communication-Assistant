# Stage 1: Domain and Requirement Study

## Purpose

Stage 1 establishes what the project will build, whom it is intended to support, and how success will be measured. No large dataset should be collected and no final model should be selected until the team agrees on these foundations.

## Stage Deliverables

- Agreed problem statement
- Identified users and use cases
- Clear inclusion and exclusion boundaries
- Functional and non-functional requirements
- Dataset and collection strategy
- Initial MediaPipe and model strategy
- Ethical and accessibility rules
- Risks, assumptions, and success criteria

## Review Method

The AI lead should walk the team through each document. Unresolved decisions should be recorded in the checklist. Stage 1 is complete only when the project supervisor and team agree that the first release is an isolated-sign recognition prototype rather than unrestricted ISL translation. Stage 2 then begins implementation of the data-collection application and its three-sign pilot setup.
